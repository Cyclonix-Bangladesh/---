ইস্ত্রি ভাই — Online Order + Admin version

1. Supabase.com এ free account/project খুলুন.
2. SQL Editor এ supabase-setup.sql-এর সব code Run করুন.
3. Authentication > Users থেকে নিজের admin email/password user তৈরি করুন.
4. Project Settings > API থেকে Project URL এবং anon/public key কপি করুন.
5. config.js-এ YOUR_SUPABASE_URL এবং YOUR_SUPABASE_ANON_KEY বদলান.
6. GitHub repository-তে এই নতুন files upload/replace করুন.
7. Customer link: index.html
8. Admin link: /admin.html

Customer page-এ Admin tab নেই। সব customer order online database-এ যাবে।
